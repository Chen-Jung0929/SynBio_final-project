II

The Pancreatic Tumor Microenvironment (PDAC TME)

Pancreatic ductal adenocarcinoma (PDAC) remains a lethal malignancy with a 5-year survival rate below 12%. A key challenge is the dense desmoplastic stroma that acts as a physical and immunological barrier.

Desmoplastic Stroma: Abundant cancer-associated fibroblasts (CAFs) and extracellular matrix elements.
Immunological Barrier: Immunosuppressive stroma limits T-cell infiltration and efficacy.
Biomarker Scarcity: Lack of single tumor-specific antigens, causing off-target safety risks.

TME Structural Layers

Dense Fibrotic Stroma (CAFs & Collagen)
Immunosuppressive Cells (MDSCs, Tregs)
Malignant Epithelial Cells (PDAC)
III

Why a Single Marker is Insufficient

Standard targeting strategies rely on highly overexpressed single proteins (e.g., MSLN or CEA). However, these markers are frequently expressed at lower levels in healthy tissues (e.g., gastrointestinal tract, lung).

On-Target, Off-Tumor Toxicity

Single-antigen chimeric antigen receptor (CAR) therapies cannot distinguish between low-expressing healthy tissue and high-expressing tumor tissue, causing severe systemic toxicity.

Toxicity Scenario

Healthy Cell Low Expression
Single CAR-T Cell
Toxicity Triggered (OFF-Target)
IV

The AND-Gate Biosensor Paradigm

To prevent off-target toxicity, we engineer logic-gated synthetic circuits that require the simultaneous presence of two distinct inputs (Input A AND Input B) to trigger activation.

Animation concept: Watch how single-marker overlaps resolve into a strict 2D decision boundary.
V

Discovery Cohort & Sample Size

To build a robust and unbiased pipeline, we combined sequencing data from primary pancreatic tumors (TCGA-PAAD) and healthy pancreas tissue (GTEx). Values were harmonized using the TOIL pipeline.

Microarray Validation: For external validation, the GSE62452 dataset from GEO was used to test cross-platform transferability.

Unbiased Selection Pipeline

Our pipeline proceeds through nine steps to identify candidate pairs starting from genome-wide transcripts down to math modeling and validation.

VII

Volcano plot: from expression matrix to each gene-dot

This slide derives the volcano plot instead of only showing it: expression values are split into PDAC and normal groups, summarized as log2FC, tested for FDR, and then mapped into x/y coordinates.

Input: gene expression matrix, columns = samples.
Visual mapping: x = tumor vs normal expression difference; y = statistical confidence; dot = one gene.
Conclusion / limit: prioritizes tumor-high candidates; does not prove causality or protein-level sensorability.
VIII

Machine learning as feature prioritization

The classifier is not presented as a diagnostic device. It is a computational filter that ranks genes by how much they help distinguish discovery-cohort PDAC from normal pancreas.

Interpretation guardrail

Feature prioritization, not clinical diagnosis. Near-perfect AUC may reflect both biology and TCGA-vs-GTEx cohort effects.

IX

SHAP: decomposing one model decision

SHAP values are introduced as a decomposition of the trained classifier output for a sample: which gene values push the probability toward PDAC, and which pull it toward normal.

Required caution

SHAP explains the model decision. It does not prove biological causality.

X

SHAP threshold: where expression changes the model vote

The threshold is derived from a dependence plot: expression values are plotted against SHAP values and the crossing point at SHAP = 0 is treated as a model-inferred activation boundary.

threshold = model-derived decision boundary
not biochemical Kd
XI

Pair selection: why UBE2S + CCR6 was selected

Candidate genes are paired, each pair is scored by tumor double-high rate, normal double-high leakage, and a correlation penalty, and the selected pair is then inspected as a 2D AND-gate scatter.

AND ON: UBE2S high AND CCR6 high.
Caution: Correlation = 0.714. Functionally divergent, but not statistically orthogonal.
XII

Hill equation: converting expression into AND-gate output

Raw expression is normalized to 0–1, transformed through two Hill response curves, and multiplied so that the output becomes high only when both UBE2S and CCR6 are high.

Output = Pbasal + Vmax · H(UBE2S) · H(CCR6)
H(X) = Xn / (KXn + Xn)
K_A and K_B are model-inferred expression thresholds. They are not biochemical dissociation constants.
XIII

Random-pair control: is UBE2S + CCR6 better than chance?

This negative control asks whether two random genes from the filtered gene universe could routinely achieve the same AND-gate AUC.

If many random pairs perform similarly, our candidate is not special.
If UBE2S + CCR6 lies beyond the random background, it supports non-random prioritization.
Caution: This control tests statistical non-randomness, not biological causality.
XIV

Threshold sensitivity: what if the inferred K values are wrong?

Because SHAP-derived K values are model-inferred rather than experimentally measured, we perturb K_A and K_B by ±10%, ±25%, and ±50%, then recompute output, AUC, and accuracy.

AUC stability means ranking remains robust.
Accuracy changes mean the final ON/OFF decision still requires calibration.
Caution: This is computational robustness, not biochemical affinity validation.
XV

External validation: dataset/platform shift changes interpretation

Discovery thresholds learned from RNA-seq are transferred to a microarray cohort. Specificity remains high, but sensitivity collapses, so the result is not a simple pass/fail story.

high-specificity computational candidate
not a validated sensitive PDAC detector
XVI

Summary & Wet-Lab Translation

The revised logic separates validation modules: random-pair control tests chance, threshold sensitivity tests parameter uncertainty, and external validation tests dataset/platform shift.

What we have: a high-specificity computational candidate pair and transparent derivation of each figure.
What remains: platform calibration, protein/RNA sensor design, and wet-lab validation in PDAC and healthy cell models.
Design guardrail: computational prioritization is not biological causality.

Validation logic

Against chance: random-pair background
Against parameter uncertainty: K sensitivity
Against platform shift: external microarray validation
